# Как выложить приложение в интернет бесплатно и установить на телефон

Приложение — это просто набор файлов (HTML, CSS, JavaScript и данные). Сервер не нужен.
Ниже два способа: **GitHub Pages** (рекомендуется, код уже лежит на GitHub) и **Netlify**.

---

## Способ 1. GitHub Pages (5 минут)

1. Откройте на компьютере или телефоне страницу репозитория на GitHub:
   `https://github.com/karimovnaaliya/povsednevnaya`.
2. Если приложение лежит в отдельной ветке (сейчас это `claude/new-session-lb2jrb`), сначала
   объедините её с основной: вкладка **Pull requests** → **New pull request** → выберите эту ветку →
   **Create pull request** → **Merge pull request**. (Можно и не объединять: в шаге 5 просто выберите
   эту ветку.)
3. Нажмите вкладку **Settings** (Настройки) вверху страницы репозитория.
4. В меню слева выберите **Pages**.
5. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: выберите `main` (или ветку с приложением) и папку `/ (root)`;
   - нажмите **Save**.
6. Подождите 1–3 минуты и обновите страницу. Вверху появится адрес вида
   `https://karimovnaaliya.github.io/povsednevnaya/`. Это и есть ваше приложение.

> Если репозиторий приватный, GitHub Pages на бесплатном тарифе может быть недоступен.
> Тогда сделайте репозиторий публичным (Settings → General → Danger Zone → Change visibility)
> или используйте способ 2.

## Способ 2. Netlify (без настройки GitHub)

1. Скачайте репозиторий архивом: на странице GitHub нажмите зелёную кнопку **Code** →
   **Download ZIP**, распакуйте архив на компьютере.
2. Откройте `https://app.netlify.com/drop` и войдите (можно через GitHub или почту).
3. Перетащите **распакованную папку** (в ней должен быть файл `index.html`) в окно браузера.
4. Через несколько секунд Netlify покажет адрес вида `https://что-то.netlify.app`. Готово.
   В настройках сайта (**Site configuration → Change site name**) можно выбрать понятное имя.

## Установка на телефон (как обычное приложение)

### Android (Chrome)
1. Откройте адрес приложения в **Chrome**.
2. Нажмите меню **⋮** (три точки справа вверху).
3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.
4. Иконка «Путь к Корану» появится на главном экране. Открывайте приложение с неё.

### iPhone (Safari)
1. Откройте адрес приложения именно в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Прокрутите и выберите **«На экран „Домой“»**, затем **«Добавить»**.
4. Открывайте приложение с иконки на главном экране.

### Чтобы всё работало без интернета
- После установки один раз откройте приложение с интернетом и подождите минуту: уроки, дуа и
  короткие суры сохранятся на телефоне.
- Аудио, которое вы хотя бы раз прослушали, тоже сохраняется. Чтобы скачать звук целой суры, откройте
  «Коран» → «Читать и слушать» → сура → **«Скачать аудио»**.
- Время намаза сохраняется на месяц вперёд.

### Чтобы не потерять прогресс
Прогресс хранится только на телефоне. Раз в неделю: **Ещё → Настройки → «Сохранить копию в файл»**,
и отправьте файл себе в Telegram или WhatsApp. На новом телефоне: **«Восстановить из файла»**.

## Для разработчика

- Локальный запуск: `python3 -m http.server 8765` в папке проекта, затем `http://localhost:8765`.
- После любых изменений файлов: `node tools/build-precache.mjs` (обновляет список офлайн-файлов
  и версию service worker, иначе телефоны не получат обновление).
- Проверка контента: `node tools/validate.mjs`. Тесты: `node tests/smoke.cjs 375`,
  `node tests/interact.cjs`, `node tests/offline.cjs`.
- Обновить данные Корана: `NODE_USE_ENV_PROXY=1 node tools/fetch-quran.mjs 1 2 18 36 55 56 67 78-114`.
