# Путь к Корану

PWA для ежедневных занятий: чтение Корана с цветным таджвидом, курс из 6 уровней, заучивание сур,
намаз и дуа по ханафитскому мазхабу, основы ислама, календарь занятий, время намаза для Оша.

- Публикация и установка на телефон: [DEPLOY.md](DEPLOY.md)
- Статус работы: [PROGRESS.md](PROGRESS.md)
- Дизайн-система: [DESIGN.md](DESIGN.md), схема контента: [CONTENT_SCHEMA.md](CONTENT_SCHEMA.md)
- Аудио: [AUDIO.md](AUDIO.md), время намаза: [docs/PRAYER_TIMES.md](docs/PRAYER_TIMES.md)

Запуск: `python3 -m http.server 8765` → http://localhost:8765
