# Бриф для агента-исследователя контента

Ты пишешь контент для приложения «Путь к Корану»: PWA для русскоязычной мусульманки из Оша
(Кыргызстан), которая месяц учится читать Коран и уже знает арабский алфавит. Полный исходный
запрос лежит в `docs/PROMPT.md`. Прочитай разделы 0, 3 (твой подраздел) и 7.

## Обязательные правила

1. **Язык:** весь текст на русском, тон простой, тёплый и уважительный («вы»). Арабский пишется
   арабской графикой, рядом всегда латинская транслитерация (`tr`) и русский перевод (`ru`).
2. **Ахлю-с-Сунна валь-Джама'а, ханафитский мазхаб, матуридитская акида.** Фикх (намаз, тахарат,
   хайд, пост и т.д.) только по ханафитскому мазхабу. Другие мазхабы можно упомянуть короткой
   нейтральной пометкой (`callout`, `tone:"note"`).
3. **Аяты Корана НИКОГДА не набирай по памяти.** Для Корана используй блоки `ayah`, `ayahs`,
   `quran-words` и аудио `{kind:"ayah"|"word"}`. Скачанные данные лежат в `data/quran/sNNN.json`
   (суры 1, 2, 18, 36, 55, 56, 67, 78–114): там у каждого аята есть `words`, их номера с 1
   (`"113:2"`, слова `[1,2]`). Открой файл и найди нужное слово, чтобы номер был точным. Другие суры:
   `https://api.alquran.cloud/v1/ayah/{s}:{a}/quran-uthmani` и
   `https://api.quran.com/api/v4/verses/by_key/{s}:{a}?words=true&word_fields=text_uthmani`.
   В Node используй `NODE_USE_ENV_PROXY=1 node ...`, в shell `curl -s`.
4. **Дуа и хадисы:** текст бери из надёжных источников (sunnah.com, Hisn al-Muslim/«Крепость
   мусульманина», dorar.net, islamqa для ссылок, hadeethenc.com: там есть русский перевод) и
   сверяй минимум с двумя. Указывай номер хадиса и ссылку. Что не проверено, не включай.
5. **Источники:** у каждого урока и темы есть `sources` с реальными ссылками, которые ты открыл.
   Предпочтение: quran.com, alquran.cloud, sunnah.com, ханафитские тексты (Нур аль-Идах, Мухтасар
   аль-Кудури, Мараки аль-Фалях, аль-Хидая, Радд аль-Мухтар), сайты муфтиятов (muftiyat.kg,
   dumrf.ru, dumrt.ru), azan.ru (ханафитский), umma.ru, islam-today.ru, hadeethenc.com,
   askimam.org и darulifta-deoband.com (ханафитские фетвы), islamqa.org (ханафитский раздел).
6. **Схема:** строго `CONTENT_SCHEMA.md`. После записи файла запусти `node tools/validate.mjs`
   (если файла ещё нет, проверь JSON через `node -e "JSON.parse(require('fs').readFileSync('путь'))"`).
7. **Заглушки запрещены:** никаких TODO, «скоро», lorem ipsum, пустых полей.
8. **Вопросы:** чем больше, тем лучше; минимум 30 на крупный раздел. Используй разные типы
   (`mcq`, `truefalse`, `listen`, `fill`, `match`, `connect`, `order`, `sort`, `tajweed`).
   У каждого вопроса есть `explain`, понятное объяснение правильного ответа.
9. Не изображай людей и живых существ; иллюстрации только как скромные SVG-силуэты без лиц.
10. Пиши только в свои файлы (они перечислены в задании). Чужие файлы и код приложения не трогай.
11. Изображение Пророка ﷺ: после имени ставь ﷺ, после сподвижников (да будет доволен ими Аллах)
    можно ставить «(р.а.)».
