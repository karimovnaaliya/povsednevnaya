# Время намаза для Оша: какой метод расчёта использовать

Итоговая конфигурация лежит в `data/misc/prayer-config.json`.

## Итог

| Параметр | Значение |
|---|---|
| API | Aladhan (`https://api.aladhan.com/v1/timings` / `/calendar`) |
| Координаты | Ош, 40.5283 с.ш., 72.7985 в.д., `Asia/Bishkek` (UTC+6) |
| Метод | `method=99` (свой), `methodSettings=18,null,16` (Фаджр 18°, Иша 16°) |
| Аср | `school=1`, по Абу Ханифе (тень вдвое длиннее предмета) |
| Поправки | `tune=0,0,0,0,1,7,0,0,0`: Аср +1 мин, Магриб +7 мин (ихтият) |
| Сухур | заканчивается со временем Фаджра (у Муфтията колонка «Багымдат / Сухур» общая) |
| Кибла из Оша | **245,6°** от севера по часовой стрелке (≈ запад-юго-запад), расстояние до Каабы ≈ 3 759 км |
| Запасной вариант | `method=3` (MWL, 18°/17°) с той же поправкой `tune` |

Порядок полей в `tune` у Aladhan: Imsak, Fajr, Sunrise, Dhuhr, Asr, Maghrib, Sunset, Isha, Midnight.

Пример запроса на месяц:

```
https://api.aladhan.com/v1/calendar/2026/11?latitude=40.5283&longitude=72.7985&method=99&methodSettings=18,null,16&school=1&tune=0,0,0,0,1,7,0,0,0&timezonestring=Asia/Bishkek
```

## Что удалось и что не удалось проверить

1. **Официальный календарь Муфтията.** Духовное управление мусульман Кыргызстана (КМДБ) публикует
   таблицы для каждого населённого пункта: Ош: `https://muftiyat.kg/kg/calendar/2/`, Рамадан для Оша:
   `https://muftiyat.kg/ru/calendar/2/orozo/` (столбцы «Багымдат / Сухур, Күн, Бешим, Аср, Шам / Ифтар,
   Куптан»). Таблица на сайте подгружается скриптом, а сам домен muftiyat.kg (как и akipress.org,
   sajda.com, islam.global) из среды разработки **не открывается** (DNS заблокирован прокси). Поэтому
   прямой построчной сверки с официальной таблицей нет. Это главное ограничение исследования.
2. **Косвенные данные.** Поисковая выдача показала, что сервис Sajda считает время для Оша «по методу
   КМДБ (muftiyat.kg)» с ханафитским асром. Опубликованные им строки для Оша:
   - 12 сентября: Фаджр 05:13, Восход 06:46, Зухр 13:05, Аср 17:34, Магриб 19:30, Иша 20:45;
   - 19 февраля 2026 (Рамадан): сухур 06:26, ифтар 18:55 (те же цифры дал календарь e-corlu).
3. По этим строкам подобраны параметры Aladhan (см. таблицу ниже): совпадение до минуты по всем
   шести временам.

## Рекомендации для приложения

- Брать месяц целиком через `/v1/calendar/{год}/{месяц}` и кэшировать (офлайн).
- В настройках дать ручную поправку ±минуты для каждого намаза, чтобы пользователь мог подогнать время
  под календарь своей мечети или Муфтията.
- Текст рядом со временем: «Расчёт по параметрам, близким к календарю Муфтията Кыргызстана. Для
  точности сверяйтесь с календарём вашей мечети».
- Для других городов использовать те же `methodSettings`, `school` и `tune`, меняя координаты.

## Кибла

Азимут по большому кругу из Оша (40.5283, 72.7985) на Каабу (21.4225, 39.8262):

```
θ = atan2(sin Δλ · cos φ2, cos φ1 · sin φ2 − sin φ1 · cos φ2 · cos Δλ) = 245,59°
```

Совпадает с `https://api.aladhan.com/v1/qibla/40.5283/72.7985` → `direction: 245.594`.
Это 245,6° от истинного севера (на 24,4° южнее направления на запад). Магнитное склонение в Оше
около +4…+5° (восточное), поэтому для магнитного компаса, если приложение не учитывает склонение,
нужно направление ≈ 241°. Лучше получать истинный курс через `deviceorientationabsolute` или
`webkitCompassHeading`.
